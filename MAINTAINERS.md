# Maintainers

| Name | GitHub | Role |
|---|---|---|
| Flux Contributors | [@lukema95](https://github.com/lukema95) | Contracts, tooling, documentation |

## Responsibilities

- Review and merge pull requests.
- Triage security reports according to [SECURITY.md](./SECURITY.md).
- Keep the `main` branch green: build, tests, coverage and Slither.
- Cut releases and update [CHANGELOG.md](./CHANGELOG.md).

## Contact

Use GitHub issues for non-security topics. For security, follow [SECURITY.md](./SECURITY.md) and
contact the maintainers privately.
